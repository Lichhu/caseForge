## 简介
本文件为"环境配置管理"模块的详细 API 文档，覆盖测试环境的创建、更新、删除、查询，以及环境服务的管理能力。重点说明环境变量配置、服务地址设置、认证信息管理、环境切换机制；解释环境与项目、用例的关联关系；阐述环境继承与覆盖规则，并提供多环境配置最佳实践与安全配置建议。**新增功能**：支持HTTPS证书验证绕过，允许在测试环境中使用自签名证书进行API调试和执行。

### HTTPS证书验证绕过功能

**新增功能**：系统现在支持在环境服务级别配置HTTPS证书验证绕过，主要用于测试环境中使用自签名证书的场景。

#### 功能特性
- **服务级配置**：每个环境服务可以独立配置是否忽略HTTPS证书验证
- **运行时应用**：在执行HTTP请求时根据配置动态应用SSL验证策略
- **安全提示**：前端界面提供明确的安全警告，提醒用户仅在测试环境使用
- **自动迁移**：数据库架构自动检测并添加ignoreSslVerify列

#### 技术实现
- **实体字段**：`ignoreSslVerify: boolean` 字段存储在 `api_test_environment_service` 表中
- **服务方法**：新增 `getServiceIgnoreSslVerify()` 方法用于轻量查询SSL验证配置
- **执行集成**：在执行服务中使用undici Agent的`rejectUnauthorized: false`选项跳过证书验证
- **前端UI**：在环境维护模态框中添加开关控件和安全提示信息

### 运行时环境合并与覆盖规则
- 合并顺序：环境基础配置（baseUrl、headers、variables、secrets）作为基线；若指定服务 ID，则叠加服务的对应字段；最终形成运行时环境对象。
- 覆盖优先级：服务级别字段覆盖环境同名字段；当服务提供 baseUrl 时，会覆盖环境的 baseUrl；当服务提供 host/port 且传输为 TCP 时，会覆盖 HTTP 的 baseUrl。
- 路径拼接：若服务提供 pathPrefix 且未提供 baseUrl，则在环境 baseUrl 上追加路径前缀并去除多余斜杠。
- 默认服务选择：若未指定服务 ID，运行时会根据传输类型（HTTP/TCP）从可用服务中选择第一个匹配项。
- **SSL验证配置**：运行时根据所选服务的ignoreSslVerify配置决定是否跳过HTTPS证书验证。

### 认证信息管理与安全
- 敏感字段：环境层的令牌以明文形式提交，服务层不直接存储明文令牌，但可通过运行时合并传入。
- 存储策略：令牌在入库前进行对称加密存储；读取时解密，仅在返回给前端时显示掩码后的摘要。
- 密钥派生：加密密钥来自环境变量或回退值，确保部署一致性与安全性。
- 前端展示：返回对象包含掩码后的令牌与是否存在令牌标记，避免泄露完整凭据。
- **SSL验证安全**：忽略证书验证仅建议在测试环境使用，生产环境应保持严格的HTTPS证书验证。

**更新** 新增了SSL验证安全考虑，强调该功能仅限测试环境使用。

### API 定义与行为

#### 环境管理接口
- 列出环境
  - 方法与路径：GET /:projectId/environments
  - 请求参数：projectId
  - 返回：环境数组（公开视图，不含明文令牌）
- 创建环境
  - 方法与路径：POST /:projectId/environments
  - 请求体：SaveApiEnvironmentDto
  - 行为：若 isDefault 为真则清空该项目其他默认标记；若无默认则自动设为默认
- 更新环境
  - 方法与路径：PATCH /:projectId/environments/:environmentId
  - 请求体：SaveApiEnvironmentDto（可选字段）
  - 行为：若 isDefault 为真则清空该项目其他默认标记
- 删除环境
  - 方法与路径：DELETE /:projectId/environments/:environmentId
  - 行为：删除环境及其服务
- 获取运行时环境
  - 方法与路径：GET /:projectId/environments/:environmentId
  - 查询参数：environmentServiceId（可选）
  - 返回：合并后的运行时环境（含服务列表）

## 性能考虑
- 查询排序：服务列表按排序字段与创建时间排序，避免随机访问带来的额外开销。
- 默认环境清理：批量更新默认标记时使用范围条件，减少不必要的写放大。
- 运行时合并：仅在执行用例或集合时进行合并，避免在非必要场景重复计算。
- **SSL验证优化**：使用单例undici Agent复用连接池，避免每次请求重建证书验证配置。
- 建议：对高频查询建立合适索引（如项目+默认标记、环境+启用状态），并控制服务数量以降低合并成本。

**更新** 新增了SSL验证性能优化考虑，使用单例模式提高连接效率。

## 故障排查指南
- 环境不存在或被禁用：服务层在查询环境时会校验启用状态与作用域，若不存在将抛出异常。
- 服务不存在或被禁用：指定服务 ID 时若未找到或未启用，将抛出异常。
- HTTP 服务缺少有效 Base URL：运行时解析 HTTP 服务时若未提供 http(s) 协议的 baseUrl，将抛出错误并给出提示。
- 令牌解密失败：若加密 blob 异常，解密函数会返回空对象，需检查存储完整性与密钥一致性。
- **SSL验证问题**：如果启用忽略证书验证后仍出现连接问题，检查目标服务器的HTTPS配置和网络连通性。
- **数据库架构问题**：如果ignoreSslVerify字段缺失，系统将自动执行架构迁移添加该字段。

**更新** 新增了SSL验证和数据库架构相关的故障排查指导。

- 作用域策略：优先使用系统/个人环境承载通用配置，全局环境用于跨项目共享。
- 默认环境：每个项目保留一个默认环境，减少手动选择成本。

- 路径前缀：在服务层配置 pathPrefix，统一处理相对路径问题。
- **SSL验证配置**：仅在测试环境启用忽略证书验证，生产环境必须保持严格的HTTPS证书验证。

### 安全配置建议
- 令牌管理：仅在创建/更新时提交明文令牌，避免长期暴露；定期轮换。
- 加密密钥：确保生产环境密钥稳定且权限最小化，避免泄露。
- 访问控制：结合用户作用域限制可见与修改范围，防止越权。
- 日志脱敏：避免在日志中打印完整令牌，使用掩码或摘要展示。
- **SSL验证安全**：忽略证书验证会降低HTTPS安全性，仅应在受控的测试环境中使用，严禁在生产环境启用。
- **环境隔离**：严格区分测试和生产环境配置，防止误用忽略证书验证的配置。

### HTTPS证书验证绕过使用指南

#### 适用场景
- 开发环境调试使用自签名证书的API服务
- 测试环境验证内部API的HTTPS通信
- 临时绕过证书问题以快速定位网络配置问题

#### 配置步骤
1. 打开环境维护面板，选择目标环境
2. 点击"新增服务"或编辑现有服务
3. 在"HTTPS证书"部分勾选"忽略校验"开关
4. 填写服务地址（建议使用https://开头的URL）
5. 保存配置

#### 注意事项
- 该功能仅建议在测试环境使用
- 启用后会跳过所有HTTPS证书验证，包括域名验证
- 生产环境应始终使用有效的SSL证书
- 如需长期使用，建议配置正确的SSL证书而非忽略验证

#### 故障排除
- 如果启用后仍无法连接，检查目标服务器的HTTPS配置
- 确认服务地址格式正确（https://hostname:port/path）
- 验证网络连接和目标服务可用性
- 检查防火墙和代理设置是否影响HTTPS连接
